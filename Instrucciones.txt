Desarrollar una aplicación transaccional en la que se puedan agregar registros y de esta forma observar dinámicamente como afecta esto las gráficas o dashboards. La aplicación debe tener a las 3 herramientas, Power BI, tableu y MCP. Para Power BI y tableu se establecen mínimo 7 objetivos. Para MCP debe adaptarse a los planteamientos que surgen. La aplicación debe mostrar los dashboards. Por cada objetivo, es un dashboard, es decir, si se plantean 7 objetivos, serán 7 hojas en Power BI.
